# CEF-500

Sistema de Gestão Acadêmica desenvolvido em Python como projeto acadêmico em equipe durante o primeiro semestre de Ciência da Computação na UDF.

📌 Funcionalidades
Cadastro de estudantes
Registro de notas e frequência
Validação de dados
Cálculo de médias por disciplina
Cálculo da frequência global
Geração de relatório acadêmico
Classificação da situação do aluno
💻 Tecnologias
Python
👨‍💻 Participação

Projeto desenvolvido em equipe, com participação significativa na implementação e desenvolvimento do código da aplicação.

🎓 Contexto

Projeto acadêmico desenvolvido durante o primeiro semestre de Ciência da Computação na UDF.
